# Burka — сайт кафе кавказской кухни в Мекке

Одностраничный сайт с меню, корзиной, картой, отзывами и переключением языков
(русский / арабский / английский). Валюта — саудийский риал (SAR).

Сборки нет: открыл `index.html` — и всё работает. Без npm, без фреймворков,
без обращений к внешним серверам (шрифты лежат локально, карта подгружается
только по клику).

## Что уже сделано

## Откуда взято оформление

Узоры на сайте не декоративная абстракция, у каждого есть источник:

| Элемент | Что это |
|---|---|
| Фон страницы | **Гирих** — исламская геометрия из переплетающихся восьмиконечных звёзд |
| Форма фотографий | **Стрельчатая арка (михраб)** — портал мечети и медресе; ею обрезаны фото в шапке, галерее и блоке «О нас» |
| Разделители разделов | **Кубачинская лоза «мархарай»** — дагестанская златокузнечная резьба. Прорисовывается, когда попадает в кадр |
| Маркер в вопросах | **Бараний рог** — кавказский ковровый мотив |
| Цвета | Тёмная зелень кубачинской эмали, марена кайтагской вышивки, золото насечки по чёрному металлу |

Все узоры — SVG прямо в разметке, картинок для них не нужно.

## Что нужно заменить перед публикацией

Всё правится в одном файле — `assets/js/data.js`.

| Что | Где именно | Сейчас стоит |
|---|---|---|
| **Отзывы** | `reviews` + флаг `reviewsAreDemo` | Демо-тексты и жёлтая плашка-предупреждение над ними |
| **Адрес** | `contacts.address` | «Мекка, Саудовская Аравия» — точный адрес нам не передали |
| **Координаты карты** | `map.lat`, `map.lng` | Центр Мекки (Заповедная мечеть) |
| **Часы работы** | `contacts.hours` | «Ежедневно 09:00 — 23:00» — поставлено по умолчанию, проверьте |
| **Цены 5 блюд** | позиции с `preorder: true` | Взяты со старой версии страницы, см. ниже |
| **Фото 6 блюд** | поле `img: null` | Пока показывается узорная заглушка |

### Про отзывы — важно

На странице заведения настоящих отзывов нет (форма комментариев пустая), поэтому
сочинять их я не стал. В `reviews` лежат **демонстрационные** тексты, и над блоком
висит заметная плашка: «Демонстрационные отзывы, замените их настоящими».

Как заменить:

1. Соберите живые отзывы из WhatsApp, Telegram или Instagram.
2. Впишите их в массив `reviews` (имя, город, оценка, текст на трёх языках).
3. Поставьте `reviewsAreDemo: false` — плашка исчезнет.

Пока настоящих отзывов нет, лучше оставить плашку: она честно предупреждает,
что тексты учебные.

### Про 5 блюд «под заказ»

На текущей странице заведения 14 позиций. Ещё 5 (аварский хинкал со шпинатом,
цельнозерновой хинкал, кукурузный хинкал, котлеты с булгуром, люля-кебаб) есть
только в старой версии страницы. Я добавил их с пометкой «Под заказ» и старыми
ценами. **Проверьте цены и наличие** — или удалите эти позиции из `menu`.

### Про фото

Фотографии блюд и галереи взяты со страницы заведения (16 снимков, лежат в
`assets/img/_src/` в оригинале). Я обрезал их под карточки и галерею, а с семи
кадров убрал рукописные подписи вроде «Голубцы» и «Аварский хинкал».

**Главное фото в шапке — отдельная, постановочная картинка** (оригинал —
`assets/img/_src/zaglavnaya.png`), а не снимок кухни. Учтите это: в разделе
«Галерея» стоит подпись «Настоящие фото наших блюд — без ретуши и стоковых
картинок». К самой галерее это по-прежнему правда, но если такое соседство
смущает — поменяйте текст `galleryLead` в `assets/js/i18n.js` или поставьте
в шапку живой снимок.

Фото не нашлось для шести позиций: тонкое чуду с тыквой, борщ, аварский хинкал
со шпинатом, кукурузный хинкал, котлеты с булгуром, люля-кебаб. Вместо них
показывается узорная заглушка «Фото скоро будет». Пришлите снимки — положите их
в `assets/img/` и укажите имя файла в поле `img`.


двойным щелчком — сайт не требует сервера.

## Куда уходят заказы

По умолчанию — **в WhatsApp**. Гость собирает корзину, жмёт «Оформить заказ»,
заполняет имя / телефон / отель, и открывается WhatsApp с готовым сообщением:

```
🌙 Новый заказ с сайта Burka

• Курзе с мясом × 2 = 50 SAR
• Классический аварский хинкал × 1 = 45 SAR

📦 Доставка: 20 SAR
💰 ИТОГО: 115 SAR

———
👤 Имя: Ахмад
📞 Телефон: +966 50 123 45 67
📍 Адрес: Hilton Suites Makkah, 1204
```

Номер задаётся в `data.js` → `contacts.whatsapp`.

### Дублирование заказов в Telegram (по желанию)

Гость может собрать корзину и не нажать «Отправить» в WhatsApp — тогда вы о
заказе не узнаете. Чтобы этого не случалось, есть маленький сервер, который
получает копию заказа в момент нажатия кнопки:

```bash
cd telegram
cp .env.example .env      # впишите BOT_TOKEN и CHAT_ID
node server.js
```

Затем в `data.js` укажите:

```js
orderEndpoint: 'http://localhost:8788/api/order'
```

Токен бота даёт [@BotFather](https://t.me/BotFather), а `CHAT_ID` — 
[@userinfobot](https://t.me/userinfobot). Все заказы дополнительно пишутся в
`telegram/orders.log`, даже если Telegram недоступен.

## Настройки, которые могут пригодиться

В `data.js`:

```js
delivery: {
  fee: 20,          // стоимость доставки по Мекке, SAR
  freeFrom: null,   // поставьте 300 — и доставка станет бесплатной от 300 SAR
}
```

Пометки на карточках блюд:

```js
hit: true        // значок «Хит»
preorder: true   // значок «Под заказ»
```

Заставка:

```js
preloader: {
  enabled: true,          // false — отключить совсем
  oncePerSession: true,   // показывать только при первом открытии вкладки
  darkMs: 450,            // тёмный экран перед анимацией
  animMs: 2100,           // сама анимация
  fadeMs: 850             // растворение
}
```

## Публикация

Залейте всю папку (кроме `dev-server.js`, `telegram/` и `assets/img/_src/`) на
любой хостинг статики — Netlify, Vercel, GitHub Pages, обычный хостинг по FTP.
Ничего настраивать не нужно.

Если поднимаете приёмник заказов в Telegram — в `telegram/.env` замените
`ALLOW_ORIGIN=*` на адрес сайта.
